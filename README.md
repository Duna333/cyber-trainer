# Кибер-карточки Югры
Интерактивный тренажёр по цифровой безопасности для школьников
(для размещения на платформе «Цифровой гражданин Югры»)

## Что это
Работающий прототип обучающего веб-приложения: 8 карточек-ситуаций,
5 разных типов заданий, мгновенная обратная связь, подсчёт результата,
оформление в стиле портала «Цифровой гражданин Югры».

Треки: базовый закрыт полностью, продвинутый — 3 из 4 пунктов
(профиль ученика с сохранением прогресса, ачивки, экспорт сертификата).

## Структура проекта
```
cyber-trainer/
├── index.html          — разметка (3 экрана: приветствие, карточка, результат)
├── styles/
│   └── main.css        — все стили, включая режим высокого контраста
├── scripts/
│   └── app.js          — логика: карточки, задания, профиль, сертификат
├── assets/
│   └── images/         — папка для картинок (иконки берутся из эмодзи, файлы не требуются)
└── README.md
```

## Как запустить
1. Скачайте и распакуйте архив.
2. Откройте index.html в браузере (двойной щелчок) — сборка не нужна.
3. Для разработки откройте папку в VS Code и используйте расширение
   Live Server (правый клик по index.html → Open with Live Server).

## Как встроить в портал
Положите папку на сервер портала и вставьте в нужный раздел:
```html
<iframe src="cyber-trainer/index.html" style="width:100%;height:900px;border:0"></iframe>
```
Внешних зависимостей нет: ни CDN, ни шрифтов, ни картинок из сети.

## Типы заданий (все 5 из 5)
| Тип | Карточки |
|---|---|
| Выбор ответа | «Редкий скин за пароль», «Незнакомец в соцсети», «Травля в чате класса» |
| Верно / неверно | «Пугающее письмо» (фишинг), «Пароль 123456» |
| Сопоставление | «Ситуация и реакция» (4 пары) |
| Сортировка | «Что можно рассказывать?» (2 корзины, 6 карточек) |
| Порядок действий | «Аккаунт взломали!» (4 шага) |

## Как добавить свои карточки
Все карточки лежат в начале файла scripts/app.js в массиве CARDS.
Добавьте объект с полями id, icon, type, tag, title и данными задания —
новая карточка появится автоматически. Поддерживаемые значения type:
choice (выбор ответа), tf (верно/неверно), match (сопоставление),
sort (сортировка), order (порядок действий).

## Соответствие требованиям кейса
- Светлое оформление, карточка видна сразу
- Цветовая схема из кейса (#f5f7fa / #ffffff / #1e5aa8 / #1f2937 / #1e7e34 / #c62828), шрифт Arial
- Метка «Цифровой гражданин Югры» + 🛡 в шапке, без сторонних логотипов
- Мгновенная обратная связь с объяснением «почему»
- Результат: процент, медаль, счёт «X из 8»
- «Фишка»: сертификат PNG с именем, классом и ачивками
- Встроение: iframe

## Хранение данных
Профиль, прогресс и настройки доступности сохраняются в localStorage
браузера ученика. Никакие данные никуда не отправляются.
